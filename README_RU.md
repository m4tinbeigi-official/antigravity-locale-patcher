# Патч локали и региона для Antigravity

Автоматический инструмент для исправления и обхода ошибки ограничения местоположения/региона в настольном приложении Google Antigravity для macOS.

* [English documentation](README.md)

---

## Введение
Этот патч изменяет локальный архив `app.asar` внутри настольного приложения Antigravity. Он подменяет часовой пояс и локаль окна браузера на фронтенде и внедряет соответствующие переменные окружения в процесс языкового сервера на базе Go. Это предотвращает появление предупреждений о блокировке региона в клиентском приложении (например, «К сожалению, этот аккаунт не подходит для использования Antigravity, так как он недоступен в вашем регионе»).

## Требования
* macOS
* Установленный Google Antigravity (в `/Applications/Antigravity.app` или `~/Applications/Antigravity.app`)
* **Node.js НЕ требуется** (установщик автоматически использует встроенный Node.js из Antigravity или скачивает портативную версию при необходимости).

## Инструкция по использованию

### Способ 1: Быстрая установка в один клик (Рекомендуется)
Вам не нужно скачивать или клонировать этот репозиторий. Просто откройте терминал и выполните следующую команду:
```bash
curl -sSL https://raw.githubusercontent.com/m4tinbeigi-official/antigravity-locale-patcher/main/patch.sh | bash
```
*(Примечание: Если права записи ограничены для системной папки приложений macOS, установщик автоматически запросит ваш пароль для запуска с повышенными привилегиями через sudo).*

### Способ 2: Ручная установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/m4tinbeigi-official/antigravity-locale-patcher.git
   cd antigravity-locale-patcher
   ```
2. Предоставьте права на выполнение и запустите скрипт:
   ```bash
   chmod +x patch.sh
   ./patch.sh
   ```
3. Перезапустите приложение Antigravity.
