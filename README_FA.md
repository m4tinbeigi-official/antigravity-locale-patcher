# پچر ریجن و موقعیت جغرافیایی آنتی‌گرویتی

ابزاری خودکار جهت پچ و دور زدن ارور محدودیت جغرافیایی و ریجن در نسخه دسکتاپ نرم‌افزار گوگل آنتی‌گرویتی برای مک‌او‌اس.

* [English documentation](README.md)

---

## معرفی
این اسکریپت فایل آرشیو محلی `app.asar` نرم‌افزار دسکتاپ Antigravity را ویرایش می‌کند. این ابزار با شبیه‌سازی (Spoofing) منطقه زمانی و زبان مرورگر در بخش فرانت‌اند و تزریق متغیرهای محیطی متناظر در پروسه بک‌اند سرور زبان، مانع از نمایش ارور عدم دسترسی به دلیل موقعیت جغرافیایی می‌شود.

**پشتیبانی از اپل سیلیکون (سری M1/M2/M3/M4):** ویرایش یک برنامه الکترون بر روی پردازنده‌های اپل سیلیکون، امضای دیجیتال (Codesign) آن را باطل کرده و باعث می‌شود سیستم‌عامل مک در هنگام اجرا آن را بلافاصله کرش (بسته) کند. این اسکریپت در پایان کار، برنامه `Antigravity.app` را به صورت خودکار با یک امضای محلی مجدداً امضا می‌کند تا به طور کامل و بدون مشکل روی مک‌های سری M و اینتل اجرا شود.

## پیش‌نیازها
* سیستم‌عامل macOS (پردازنده‌های Intel یا Apple Silicon سری M)
* نصب بودن برنامه Antigravity (در مسیر `/Applications/Antigravity.app` یا `~/Applications/Antigravity.app`)
* **نیاز به نصب Node.js نیست** (پچر به طور خودکار از نسخه داخلی Antigravity استفاده می‌کند یا در صورت لزوم نسخه پرتابل Node.js را خودکار دانلود و اجرا می‌کند).

## نحوه استفاده

### روش اول: نصب سریع و تک‌خطی (توصیه شده)
نیازی به دانلود یا کلون کردن پروژه ندارید. فقط کافیست ترمینال مک خود را باز کرده و دستور زیر را اجرا کنید:
```bash
curl -sSL https://raw.githubusercontent.com/m4tinbeigi-official/antigravity-locale-patcher/main/patch.sh | bash
```
*(نکته: در صورتی که دسترسی نوشتن به پوشه برنامه‌ها در سیستم شما محدود باشد، پچر به صورت خودکار از شما درخواست وارد کردن رمز عبور مک را می‌کند).*

### روش دوم: نصب دستی
۱. مخزن پروژه را کلون کنید:
   ```bash
   git clone https://github.com/m4tinbeigi-official/antigravity-locale-patcher.git
   cd antigravity-locale-patcher
   ```
۲. به اسکریپت اجازه اجرا داده و آن را اجرا کنید:
   ```bash
   chmod +x patch.sh
   ./patch.sh
   ```
۳. برنامه Antigravity را به طور کامل ببندید و مجدداً باز کنید.
